## 📦 كيفية الرفع على جيت هاب (GitHub)

1. **افتح مجلد المشروع في التيرمينال (Terminal / Command Prompt)**:
   ```bash
   cd d:\tabaqa
   ```

2. **تهيئة مستودع جيت (Git Repo)**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Tabaqa Agency Website (Subframe style)"
   ```

3. **إنشاء مستودع جديد على GitHub باسم `tabaqa` ثم ربطه**:
   ```bash
   git branch -M main
   git remote add origin https://github.com/USERNAME/tabaqa.git
   git push -u origin main
   ```
   *(استبدل `USERNAME` باسم حسابك في GitHub)*

## ⚡ كيفية الرفع والنشر على فيرسيل (Vercel)

### الطريقة الأولى: عبر لوحة تحكم Vercel Dashboard (الأسهل والأسرع):
1. اذهب إلى [Vercel Dashboard](https://vercel.com/new).
2. اختر **Import Git Repository**.
3. حدد مستودع `tabaqa` من حساب GitHub الخاص بك.
4. اضغط **Deploy**.
5. سيتكفل Vercel بنشر الموقع تلقائياً وتوفير رابط مجاني مثل: `https://tabaqa.vercel.app` ورابط SSL مشفر.

### الطريقة الثانية: عبر Vercel CLI (التيرمينال):
```bash
npm i -g vercel
vercel login
vercel --prod
```
